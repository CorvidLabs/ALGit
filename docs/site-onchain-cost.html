Site on chain, if the heavy files lived on IPFS

Not building it. Confidence 80% that leaving it unbuilt is right.

The public import of site origin plus tags was paid at 290.717 ALGO. The private plan for the same objects is 295.554 ALGO. Raster images are 169.060 ALGO of the object fee. Replacing those images with CID pointers leaves 133.442 ALGO private. Keeping source blobs, trees, and commits, and storing every other blob as a pointer, leaves 40.733 ALGO private. Keeping the source code and also turning specsync records and the src/data catalogues into pointers leaves 30.548 ALGO private. The algochat private import was 9.257 ALGO.

Each bar is a private fee. Full width is the as-stored plan, 295.554 ALGO. The mark is the algochat import at 9.257 ALGO.

  • As stored, 295.554 ALGO private
  • Images become CID pointers, 133.442 ALGO private
  • Source, trees, and commits stay, 40.733 ALGO private
  • Source code stays, catalogues become pointers, 30.548 ALGO private

The measured write of the full public history took 606.5 seconds, about 372 notes a second. At that rate the source-plus-pointer history is about 95 seconds, and the code-plus-pointer history is about 75 seconds. Private site was not pushed. The private fees use the same note surcharge as the offline plan, which matches that plan to the microALGO.

This does not replace the research note. The chain run, the mailboxes, and the algochat result are in onchain-git-remote.md.

If the heavy bytes were CID pointers

A pointer here is a 72-byte blob, an ipfs:// CID and a short label. Its canonical object is 80 bytes, one note, 0.001 ALGO. Any pointer under about 970 bytes of content stays on that minimum. Tree and commit sizes do not change, because a git tree stores a 20-byte object id either way. Replacing a blob does change history: the new blob has a new id, and every tree that points at it is rewritten. The prices below are that rewritten object set. They were not committed and not pushed. IPFS pinning is not in the fee. A CID with no pin does not fetch.

Is it worth it

No, for the repository as it is stored. The public payment was 290.717 ALGO and 225,869 notes. The private plan is 295.554 ALGO. That is a LocalNet proof that the bytes fit, funded so the fee could not be the reason it failed. It is the wrong remote to hand anyone for site.

No, if the only change is that images move to IPFS. 133.442 ALGO private remains, because built bundles are 41.716, the peck packs are 34.003, published JSON is 10.259, and video is 4.224. Those files are on origin/main, in the same history as the pictures.

A later private archive of the source is the case that is merely expensive. 40.733 ALGO if every non-source blob is a pointer. 30.548 ALGO if specsync snapshots and the catalogues are pointers too. Both are three to four times the algochat remote, and both sit above the budget that matched the measurements: under 10 ALGO and under a minute for a full history. The algochat-sized case is the only size that fit, and we are not building that remote either. October shows what one month costs when image, pack, bundle, and catalogue bytes are committed as git blobs.

A public on-chain remote stays a no. The public fee is a few ALGO under the private fee. Anyone who can read the chain can read the file bytes. GitHub remains the forge.

Confidence

85% is the confidence in that verdict. It is not an average of the rows below. The prices are tighter than the product call. IPFS pinning was not priced, and that cost sits outside the rating.

Claim Confidence

The verdict on this page 85%

What was checked. The fee function, 1,000 µALGO through 1,024 bytes and the protocol surcharge after that, reproduces the chain payment with zero residual once the 23 ref notes are included. The same function reproduces the offline private plan: 229,513 notes and 295.554 ALGO. The largest PNG prefixes are PNG. No raster blob is under 200 bytes, and none of the sniffed bodies is a Git LFS pointer. The path recorded when a blob first appeared and the path from git rev-list --objects never disagree on which bucket a blob is in. All 20,709 objects have a committer month, including 548 root trees the diff listing did not print. public/algorand was opened by extension: 92.2 MiB of it is .js.

What was not done. The repository was not rewritten with CID blobs, and it was not pushed a second time. Every image header was not read, only the largest and the suspicious small ones. A hand-written script under public/ would be counted with the built bundles. Moving 10% of that 41.716 ALGO into source would shift the source-plus-pointer price by about 4 ALGO. Pinning, gateways, and the durability of the CID are unmeasured.
