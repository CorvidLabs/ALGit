# Remote

## Intent

A person runs one command and their commits land on the Algorand network they named. LocalNet is where they try it. MainNet tells them the cost and waits.


## Criteria

- **REMOTE-1**  I can push a git repository to Algorand LocalNet with one command.
- **REMOTE-2**  I can ask what the same push would cost on MainNet and see the ALGO before anything is spent.
- **REMOTE-3**  I can clone that repository back off the chain and git fsck accepts it.
