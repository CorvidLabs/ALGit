### SPEC SECTION Behavioral Examples

A one-commit repository becomes one set of object notes plus one ref note. Materializing those notes produces a bare repository whose git fsck exits 0 and whose branch points at the same commit. When the mailbox has more than one branch, the work tree checks out the branch that is not an ancestor of another branch, and a slash in that name is kept. Asking for a MainNet quote prints microALGO and ALGO and leaves the chain untouched. A blob of 256 KiB plus one byte is posted to the caller's Pinata gateway. The page is a script module, so a browser shows the file list and the commit list, then the text of a file and the diff of the newest commit. The page loads the CorvidLabs design-system tokens, the sun/moon toggle, Schibsted Grotesk, and Spline Sans Mono.
