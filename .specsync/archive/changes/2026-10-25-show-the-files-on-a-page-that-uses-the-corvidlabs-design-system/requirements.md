# Requirements

### REQ-algit-4

The program SHALL serve a page on 127.0.0.1 that shows the files and the commits, and that page SHALL use the CorvidLabs design system.

Acceptance Criteria
- The page script is a module, so the file list and the commit list render.
- The page loads the design-system tokens, the sun/moon toggle, Schibsted Grotesk, and Spline Sans Mono.
