# Research

The empty page was a JavaScript syntax error. A `\n` inside the Python string that holds the page became a real line break, so the browser discarded the module and drew only the shell. A script file does not pass through that string, so the newline stays a newline escape the browser understands.

Headless Chrome on http://127.0.0.1:4711/ then showed 16 folders, 12 commit hashes, 72 file sizes, and the ALGO total 0.265338. Dot-folders start closed, which is why the archive does not fill the rail.
